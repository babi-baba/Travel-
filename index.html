Backup e ripristino

Esporta i dati dell'app in un file JSON. Il backup completo include anche i PDF e le foto archiviati, se il browser consente di leggerli. Conserva il file esportato in un luogo sicuro.

Consultazione offline

Dopo aver installato l'app e aperto i documenti sul dispositivo, potrai consultare l'interfaccia senza connessione. Conserva anche copie importanti in un archivio sicuro separato.

Cloud e privacy

TRAVEL salva ogni modifica sul dispositivo. La sincronizzazione con il cloud è manuale: avviene soltanto quando premi “Sincronizza adesso”. I documenti vengono caricati nel cloud durante questa sincronizzazione. Non inserire password, numeri completi di carte o dati non necessari.

Stampa

Usa la funzione stampa nelle sezioni Viaggi e Documenti e scegli “Salva come PDF”.
